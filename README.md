The brief asks for a single sentence, at most 200 characters, that makes a small everyday moment strange and new — an angle the reader has not met before, a surprise that lands in a single read, and a moment that stays grounded in something real.

## The entry

> At 3 a.m. the washing machine stopped mid-spin and knocked once, like a guest who knew the house was asleep but carried news that could not wait for morning.

(157 characters, one sentence.)

## How the program works

`main.ts` runs on Node 22 using only the standard library, with no network access at all. It writes the sentence to `/output/entry.txt`. Because there is no randomness and no outside input, the file it produces is identical on every run.
